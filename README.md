## Was die App kann

- Anlieferung buchen: Sack scannen, Anzahl wählen, fertig.
- Eingefüllten Sack abbuchen – mit einem Scan.
- Bestand, Reichweite und „Nächster Sack etwa am …“ je Lager auf einen Blick.
- Erinnert rechtzeitig ans Nachbestellen und Einfüllen.
- Läuft auch auf den geteilten Rosenweg-Telefonen, Anmeldung per Karte.

## Plattformen

Android (iOS möglich).
